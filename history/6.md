## Requisito: Builder Pattern API com ORDER BY e GROUP BY

### Contexto

A ORM Rochas.DapperRepository precisa suportar **agregações e agrupamento** nativamente para dar suporte à camada BWOQ (wrapper de relatórios dinâmicos) e integrações do SGEv3. Atualmente, a infraestrutura para GROUP BY e agregações existe internamente mas não é acessível pela API pública.

### Definição do Padrão

O padrão **builder pattern** expõe `Query()` como ponto de entrada que retorna um objeto builder interno. As operações de ordenação e agrupamento são **terminais** — cada uma finaliza e executa a query, retornando os resultados diretamente.

#### API Pública

```csharp
// 1. Query básica — sem ordenação, sem agrupamento
ICollection<T> results = await repo.Query(filter);

// 2. Query com ordenação — .OrderBy() finaliza e executa
ICollection<T> results = await repo.Query(filter)
    .OrderBy(new[] { "Name", "CreatedAt" });

// 3. Query com ordenação reversa
ICollection<T> results = await repo.Query(filter)
    .OrderBy(new[] { "Name" }, descending: true);

// 4. Query com agrupamento e agregação — .GroupBy() finaliza e executa
ICollection<T> results = await repo.Query(filter)
    .GroupBy(
        columns: new[] { "Category" },
        aggregations: new[] { "Amount", "Id" },
        types: new[] { DataAggregationType.Sum, DataAggregationType.Count }
    );

// 5. Query com agrupamento simples (sem agregação)
ICollection<T> results = await repo.Query(filter)
    .GroupBy(columns: new[] { "Category", "Status" });
```

#### Assinatura do GroupBy

```csharp
/// <summary>
/// Executa query com GROUP BY e agregações opcionais.
/// Método terminal — executa e retorna resultados.
/// </summary>
/// <param name="columns">Colunas de agrupamento (obrigatório, mínimo 1)</param>
/// <param name="aggregations">Colunas a agregar (opcional — se omitido, apenas agrupa)</param>
/// <param name="types">Tipo de agregação para cada coluna (opcional — deve ter mesmo tamanho de aggregations)</param>
/// <returns>Resultados agrupados e agregados</returns>
ICollection<T> GroupBy(
    string[] columns,
    string[] aggregations = null,
    DataAggregationType[] types = null
);
```

#### Assinatura do OrderBy

```csharp
/// <summary>
/// Executa query com ordenação.
/// Método terminal — executa e retorna resultados.
/// </summary>
/// <param name="sortAttributes">Colunas para ordenação (obrigatório, mínimo 1)</param>
/// <param name="descending">Ordenação descendente (padrão: false = ascendente)</param>
/// <returns>Resultados ordenados</returns>
 ICollection<T> OrderBy(
    string[] sortAttributes,
    bool descending = false
);
```

### Arquitetura Interna

#### Campos Privados do Builder

```csharp
// Dentro do QueryBuilder<T> (ou internamente no GenericRepository<T>)
private string[] _sortProps;           // preenchido por .OrderBy()
private string[] _groupProps;          // preenchido por .GroupBy()
private string[] _aggregationProps;    // preenchido por .GroupBy()
private DataAggregationType[] _aggregationTypes; // preenchido por .GroupBy()
```

#### Fluxo de Execução

```
Query(filter)
    │
    ├── .OrderBy(columns)
    │       ↓
    │   _sortProps = columns
    │       ↓
    │   EntitySqlParser.ParseEntity(filter, engine, action, filter,
    │       sortAttributes: string.Join(",", _sortProps),
    │       groupAttributes: null)
    │       ↓
    │   ExecuteCommand → ICollection<T>
    │
    └── .GroupBy(columns, aggs, types)
            ↓
        _groupProps = columns
        _aggregationProps = aggs
        _aggregationTypes = types
            ↓
        EntitySqlParser.ParseEntity(filter, engine, action, filter,
            sortAttributes: null,
            groupAttributes: string.Join(",", _groupProps))
            ↓
        [DataAggregationColumn] nas propriedades de agregação
            ↓
        ExecuteQuery → ICollection<T>
```

#### Métodos Públicos (terminais)

```csharp
// Ponto de entrada — retorna QueryBuilder
public QueryBuilder<T> Query(T filter)
{
    return new QueryBuilder<T>(this, filter);
}

// Builder interno
public class QueryBuilder<T> where T : class
{
    private readonly GenericRepository<T> _repository;
    private readonly T _filter;

    internal QueryBuilder(GenericRepository<T> repository, T filter)
    {
        _repository = repository;
        _filter = filter;
    }

    public async Task<ICollection<T>> OrderBy(string[] sortAttributes, bool descending = false)
    {
        var sort = string.Join(",", sortAttributes);
        if (descending) sort += " DESC";
        return await _repository.QueryInternal(_filter, sortAttributes: sort);
    }

    public async Task<ICollection<T>> GroupBy(
        string[] columns,
        string[] aggregations = null,
        DataAggregationType[] types = null)
    {
        var group = string.Join(",", columns);
        // Configura [DataAggregationColumn] dinamicamente ou usa método interno
        return await _repository.QueryInternal(_filter, groupAttributes: group);
    }
}
```

### Entidades de Exemplo (SGEv3)

#### Dashboard — TotalVendas por Categoria

```csharp
// Entidade de resultado para agregação
public class SalesByCategory
{
    [Key] [AutoGenerated] public int Id { get; set; }
    public string Category { get; set; }

    [DataAggregationColumn(ColumnName = "TotalAmount", AggregationType = DataAggregationType.Sum)]
    public decimal TotalAmount { get; set; }

    [DataAggregationColumn(ColumnName = "Id", AggregationType = DataAggregationType.Count)]
    public int TotalInvoices { get; set; }
}

// Uso no repositório
var results = await repo.Query(new SaleInvoice { ... })
    .GroupBy(columns: new[] { "Category" });
// SQL gerado: SELECT Category, SUM(TotalAmount), COUNT(Id) FROM SaleInvoice GROUP BY Category
```

#### Relatório Dinâmico BWOQ

```csharp
// Para agregações dinâmicas (não previstas na entidade)
var results = await repo.QueryRaw(
    "SELECT CustomerId, SUM(TotalAmount) as Total, COUNT(Id) as Count " +
    "FROM SaleInvoice WHERE Status = @status GROUP BY CustomerId",
    new Dictionary<string, object> { ["@status"] = "Paid" }
);
```

### Compatibilidade

| Cenário | Comportamento |
|---------|---------------|
| `Query(filter)` | Retorna `ICollection<T>` — compatível com código existente |
| `Query(filter).OrderBy(...)` | Retorna `ICollection<T>` — substitui `sortAttributes` param |
| `Query(filter).GroupBy(...)` | Retorna `ICollection<T>` — novo recurso |
| `await repo.Query(filter)` | Funciona via `TaskAwaiter` no builder (implicit operator) |
